# 支付参数配置清单

> 每个参数：**从哪个平台获取 · 是否敏感 · 用于测试还是生产 · 用途**。
> 规则：
> - **敏感=是** 的参数 → 一律用 `wrangler secret put <NAME>` 存入 **Cloudflare Secrets**，绝不进 GitHub/前端/localStorage/明文日志。
> - **敏感=否** 的参数可放 `wrangler.toml` 的 `[vars]`（非机密）。
> - **前端(Cloudflare Pages)永远不读取任何敏感参数**；前端只调用 `/api/*`，密钥留在 Workers。
> - 测试阶段：真实渠道参数全部留空 → 该渠道显示「暂未开放」，走 `MockProvider`（标记 TEST）。

## 0. 平台/基础设施

| 参数 | 来源平台 | 敏感 | 环境 | 用途 |
|---|---|:--:|:--:|---|
| SUPABASE_URL | Supabase 控制台 → Project Settings → API | 否 | 测试+生产 | 数据库/Auth 地址 |
| SUPABASE_ANON_KEY | 同上 | 否 | 测试+生产 | 前端可用公钥(受 RLS 限制) |
| SUPABASE_SERVICE_ROLE_KEY | 同上 | **是** | 测试+生产 | 服务端绕过 RLS，仅 Workers |
| SUPABASE_JWT_SECRET | Supabase → Auth → JWT | **是** | 测试+生产 | 校验用户 JWT |
| R2_ACCOUNT_ID | Cloudflare → R2 | 否 | 测试+生产 | R2 账户 |
| R2_ACCESS_KEY_ID | Cloudflare → R2 → API Tokens | **是** | 测试+生产 | R2 访问 |
| R2_SECRET_ACCESS_KEY | 同上 | **是** | 测试+生产 | R2 访问 |
| R2_BUCKET_PREVIEWS / R2_BUCKET_DELIVERY | 自定义 | 否 | 测试+生产 | 预览/交付桶名 |
| R2_DOWNLOAD_URL_TTL | 自定义 | 否 | 测试+生产 | 短期下载链接有效期(秒) |

## 1. 微信支付（PC 端默认 Native 扫码）

来源平台：**微信支付商户平台 pay.weixin.qq.com** + 微信公众平台(AppID)。

| 参数 | 来源 | 敏感 | 环境 | 用途 |
|---|---|:--:|:--:|---|
| WECHAT_MCH_ID | 商户平台 → 账户中心 | 否 | 生产 | 商户号 |
| WECHAT_APP_ID | 公众平台/开放平台 | 否 | 生产 | 关联应用 AppID |
| WECHAT_MERCHANT_SERIAL_NO | 商户平台 → API 安全 → API 证书 | 否 | 生产 | 商户证书序列号 |
| WECHAT_MERCHANT_PRIVATE_KEY | 申请 API 证书时生成 | **是** | 生产 | 请求签名私钥 |
| WECHAT_API_V3_KEY | 商户平台 → API 安全 → APIv3 密钥 | **是** | 生产 | 回调解密/验签 |
| WECHATPAY_PUBLIC_KEY_ID | 商户平台 → 微信支付公钥 | 否 | 生产 | 公钥 ID |
| WECHATPAY_PUBLIC_KEY | 同上 | **是** | 生产 | 平台公钥验签 |
| WECHAT_NOTIFY_URL | 我方 Workers 路由 | 否 | 生产 | 异步通知回调 |

前置资质：营业执照、对公账户、**ICP 备案域名**、微信支付商户入驻。

## 2. 支付宝（电脑网站支付 / 扫码）

来源平台：**支付宝开放平台 open.alipay.com**。

| 参数 | 来源 | 敏感 | 环境 | 用途 |
|---|---|:--:|:--:|---|
| ALIPAY_APP_ID | 开放平台 → 应用 | 否 | 生产 | 应用 AppID |
| ALIPAY_APP_PRIVATE_KEY | 本地生成密钥对(上传公钥) | **是** | 生产 | 请求签名 |
| ALIPAY_PUBLIC_KEY | 开放平台(公钥模式) | **是** | 生产 | 验签(非证书模式) |
| ALIPAY_APP_CERT | 开放平台(证书模式) | 否 | 生产 | 应用公钥证书 |
| ALIPAY_CERT | 开放平台(证书模式) | 否 | 生产 | 支付宝公钥证书 |
| ALIPAY_ROOT_CERT | 开放平台(证书模式) | 否 | 生产 | 根证书 |
| ALIPAY_NOTIFY_URL | 我方 Workers 路由 | 否 | 生产 | 异步通知回调(支付依据) |
| ALIPAY_RETURN_URL | 我方前端 | 否 | 生产 | 同步跳转(仅展示，非依据) |

前置资质：营业执照、对公账户、**ICP 备案域名**、开放平台签约"电脑网站支付/当面付"。

## 3. 银联（在线网关 / 聚合收银台，待商户通道确认）

来源平台：**中国银联 open.unionpay.com / 银联商务**，或由聚合 PSP 代开。

| 参数 | 来源 | 敏感 | 环境 | 用途 |
|---|---|:--:|:--:|---|
| UNIONPAY_MERCHANT_ID | 银联/收单机构 | 否 | 生产 | 商户号 |
| UNIONPAY_SIGN_CERT | 银联证书工具 | 否 | 生产 | 签名证书 |
| UNIONPAY_SIGN_CERT_PASSWORD | 申请时设置 | **是** | 生产 | 签名证书密码 |
| UNIONPAY_VERIFY_CERT | 银联提供 | 否 | 生产 | 验签证书 |
| UNIONPAY_FRONT_URL | 我方前端 | 否 | 生产 | 前台跳转 |
| UNIONPAY_BACK_URL | 我方 Workers 路由 | 否 | 生产 | 后台通知(支付依据) |
| UNIONPAY_ENV | 自定义 | 否 | 测试+生产 | test/prod 切换 |

## 4. Apple Pay（需 PSP 承载 + 域名验证；否则隐藏入口）

来源平台：**Apple Developer developer.apple.com** + 承载它的 **PSP**。

| 参数 | 来源 | 敏感 | 环境 | 用途 |
|---|---|:--:|:--:|---|
| APPLE_MERCHANT_ID | Apple Developer → Identifiers → Merchant IDs | 否 | 生产 | 商户标识 |
| APPLE_TEAM_ID | Apple Developer | 否 | 生产 | 团队 ID |
| APPLE_MERCHANT_DOMAIN | 已完成验证的收款域名 | 否 | 生产 | 域名验证 |
| APPLE_PAYMENT_PROCESSING_CERT | Apple Developer | 否 | 生产 | 支付处理证书 |
| APPLE_PAYMENT_PROCESSING_PRIVATE_KEY | 生成 | **是** | 生产 | 支付处理私钥 |
| APPLE_MERCHANT_IDENTITY_CERT | Apple Developer | 否 | 生产 | 商户身份证书 |
| APPLE_MERCHANT_IDENTITY_PRIVATE_KEY | 生成 | **是** | 生产 | 商户身份私钥 |
| APPLE_PSP_PROVIDER | 选定的 PSP | 否 | 生产 | 承载渠道标识 |
| APPLE_PSP_API_KEY | PSP 控制台 | **是** | 生产 | PSP 服务端 Key |

> Apple Pay 只有在 **PSP 支持 + 商户开通 + 域名验证成功 + 当前设备/浏览器支持** 四者全满足时才显示按钮，否则隐藏。**不做假按钮、不伪造成功。**
